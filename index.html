Self-maintaining APIs.

When an API provider ships a breaking change, DriftPatch finds every affected line in your codebase and proposes the fix as a ready-to-apply patch. It's Dependabot for APIs.

Scan a repo → Try a demo snippet

1. Curated breaking changes

Each rule is a real change from a public changelog or migration guide, and each one links to its source. Nothing is guessed.

2. Scan in your browser

Paste code or point it at a public GitHub repo. Files are fetched straight from GitHub, with no server, no keys and no uploads.

3. Get a patch

Every flagged line comes with its source link. Rules that can be fixed mechanically produce a unified diff and a .patch file, or a pull request via the GitHub Action.
